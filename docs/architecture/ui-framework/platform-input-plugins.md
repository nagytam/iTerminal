### Platform input plug-ins — `iConsole.Inputs.Posix` / `iConsole.Inputs.Windows`
Each supplies an `ITerminalInputSource` + input-consumer `IJob` and a DI extension called from `Program.cs`: `AddLinuxTerminalInput()` (Linux, ANSI/SGR mouse + raw stdin) and `AddInputWindowsAsync()` (Windows). The Windows path is feature-gated by `WindowsConsoleDriver` (via `Microsoft.FeatureManagement`, config in `appSettings.json`); when off — and on all non-Windows/non-driver paths — it falls back to `AddPollingConsoleKeyboard()`.
- **Loading or unavailable?** A menu-bar indicator that waits on a background fetch (`WeatherIndicator`, `QuoteIndicator`) shows a spinner while an attempt is running. Once the last attempt has failed and none is running, it says `unavailable` instead of spinning on. The job records the outcome on its service (`LastRefreshFailed`), and the failure is also traced, not discarded.
- **Memory drive sync** (`MemoryDriveSynchronizationJob`): only the sync folder's own files are loaded, because the memory drive is flat and a file in a subfolder would collide with a root file of the same name. Save failures are traced, and the job keeps running.
